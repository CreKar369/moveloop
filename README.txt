MOVELOOP DANCE GAME
===================

Quick start
-----------
Open moveloop-self-contained.html in a modern browser.
This version contains the character artwork inside the HTML and works as one file.

Project files
-------------
moveloop-self-contained.html  Recommended standalone game
moveloop.html                 Editable version using a separate image
dance-character-art.png       Original generated character artwork

Controls
--------
Phone/tablet: tap the four move buttons.
Laptop: use Left Arrow, Up Arrow, Down Arrow, and Space.

Keep moveloop.html and dance-character-art.png together if using the editable version.
